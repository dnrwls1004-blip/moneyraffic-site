Moneyraffic

개인정보처리방침

시행일: 2026년 10월 31일

Moneyraffic은 사용자의 컴퓨터에서 실행되는 마케팅 운영 도구입니다. 이 방침은 사용자가 Google 계정을 연결했을 때 어떤 데이터를 어떻게 다루는지 설명합니다.

1. 사용하는 Google 데이터

서비스권한사용 목적
Gmail메일 읽기(gmail.readonly)받은 메일을 조회하고 분류합니다.
Gmail초안 관리·메일 보내기(gmail.compose)사용자가 승인한 메일을 작성하고 발송합니다.
Google Sheets스프레드시트 읽기·쓰기(spreadsheets)크리에이터 장부와 탐색 결과를 불러오고 저장합니다.
Google Ads광고 계정 접근(adwords)사용자가 연결한 경우 광고 성과를 확인하고, 사용자가 승인한 변경을 적용합니다.

각 권한은 사용자가 Google 동의 화면에서 허용한 경우에만 사용합니다.

2. 저장 위치

연결 인증 정보와 업무 기록은 사용자의 컴퓨터에 저장합니다. 운영자는 이 데이터를 받아 보관하는 별도 서버를 운영하지 않습니다.

3. 제3자 제공

  • Google 사용자 데이터를 판매하지 않으며, 광고 목적으로 사용하지 않습니다.
  • 메일 분류나 초안 작성을 요청하면, 처리에 필요한 내용이 사용자가 선택한 AI 도구(Claude Code 또는 Codex)로 전달되어 해당 제공업체의 약관에 따라 처리됩니다.
  • 메일을 발송하거나 시트에 저장하면 해당 내용이 Google 서비스로 전송됩니다.
  • 법령에 따라 요구되는 경우를 제외하고 그 밖의 제3자에게 제공하지 않습니다.

4. Google API 제한적 사용

Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

5. 보관과 삭제

데이터는 사용자가 삭제할 때까지 사용자의 컴퓨터에 남습니다. 사용자는 프로그램 폴더와 연결 정보 파일을 지워 언제든 삭제할 수 있습니다. Google에 저장된 메일과 시트는 Google 계정에서 관리합니다.

6. 연결 해제

Google 계정의 타사 앱 권한 페이지에서 언제든 접근 권한을 철회할 수 있습니다.

7. 변경

이 방침이 바뀌면 이 페이지에 내용과 시행일을 고지합니다.
